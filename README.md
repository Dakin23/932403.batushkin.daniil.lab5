Цель: 
Научиться манипулировать DOM деревом, находить элементы, изменять содержимое и стили, а также сохранять состояние страницы между перезагрузками через localStorage.

Задание:
Реализовать интерактивные функции:
- Поиск элементов через getElementById, querySelector, querySelectorAll.
- Манипуляции с DOM: изменение текста, атрибутов, классов; добавление/удаление элементов.
- Переключение темы (светлая/тёмная) по кнопке.
- Скрытие/показ блоков по клику.
- Обработка ошибок: проверка существования элемента.
- Сохранение состояния в localStorage: при добавлении/удалении элементов и переключении темы сохранять данные; при загрузке страницы восстанавливать их.

Вариант 15. Тема «Учёный и исследователь» (список гипотез с статусами) 
Контент:
Карточки гипотез (формулировка, статус «не проверена/проверена», кнопка «Изменить статус»). 
Логика: 
«Добавить гипотезу» создаёт карточку. Кнопка «Скрыть гипотезы» скрывает секцию. Переключение темы. Обработка ошибок.
(Так же добавлена кнопка «Показать гипотезы», которая раскрывает их обратно после скрытия)
